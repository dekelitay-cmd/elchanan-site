Privacy policy

Last updated: October 26, 2026

Elchanan is a personal Telegram assistant used by its owner only. This policy explains what happens to Google user data when the owner connects a Google account.

Data accessed

  • Google Calendar: event titles, times and descriptions, to answer questions and create events on request.
  • Gmail: message headers, snippets and text of messages the owner asks about, and the ability to send a message the owner has approved.

How data is used

Data is used only to answer the owner's own requests in the Telegram chat. It is not used for advertising, profiling, or any purpose other than the owner's requests.

Storage and sharing

  • Email and calendar content is read on request and is not copied into a database. Only the chat history, notes and lists the owner creates are stored, in a private database.
  • When the assistant answers, the relevant text is sent to Google's Gemini API to generate the reply.
  • Google user data is not sold, shared with third parties or used to train models by the app owner.
  • Access credentials are stored as encrypted environment variables on the hosting provider and are never published.

Limited use

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Control and deletion

The owner can revoke access at any time at myaccount.google.com/permissions, and can delete stored chat data on request.
